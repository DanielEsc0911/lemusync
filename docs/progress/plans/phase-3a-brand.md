# Phase 3a, brand and design system

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Also follow the project skills: `lemusync-feature` (always), `lemusync-ui` (Tasks 3, 6–9), `lemusync-docs` (every task), `lemusync-security` (Tasks 2, 4: new dependencies, a tool that writes files from data).

**Goal:** LemuSync gets its look: a lemur + 90s-console-hardware brand, a token-driven Flutter design system and a modular lemur mark, all generated from one folder (`brand/`) so a palette or mark change spreads to the app, the app icons and the tray with one command. First of the four Phase 3 plans ([roadmap](../roadmap.md#phase-3-flutter-app-desktop), [D40](../../decisions.md#d40-the-desktop-ui-comes-before-the-windows-and-macos-daemon-2026-11-01)).

**Architecture:** `brand/tokens.toml` (palette primitives, semantic color roles per theme, contrast pairs, type, space, size, shape, opacity, motion) and `brand/mark/` (SVG parts with `{{placeholders}}` plus `marks.toml` compositions) are the only hand-edited brand sources. `cargo xtask brand` reads and validates them (every role in every theme, WCAG contrast pairs, no unknown placeholder, safe file names) and writes every derived file: Dart tokens, composed SVGs, app icons for all five platforms, the packaging icon and the tray pixmaps. `cargo xtask brand --check` regenerates in memory, fails on any difference or failed check, and also fails on any hard-coded design literal in `app/lib`. It runs in `just check` and in CI. Flutter widgets read only tokens (`app/lib/design/tokens/*.g.dart`) through `app/lib/design/theme.dart`.

**Tech Stack:** Rust 1.99.0 xtask with `toml` 1.1.8 + `serde` (workspace deps), new `resvg` 0.49.0 (`default-features = false`; it depends on `tiny-skia` 0.12 with `png-format`, so `resvg::tiny_skia::Pixmap::encode_png()` is available), `ico` 0.6.0, `png` 0.18 (opaque PNG for iOS; already in the graph); Flutter 3.47.6 with bundled variable fonts (Space Grotesk, Inter, JetBrains Mono; SIL OFL 1.1) and `lucide_icons_flutter` 4.0.1 (package MIT, icons ISC).

**Spec:** [brand](../../specs/ui/brand.md) (new, Task 1), [design-system](../../specs/ui/design-system.md) §Tokens, §Brand, §Components, §Accessibility, §Performance; [status-and-notifications](../../specs/ui/status-and-notifications.md) §Status model, §Desktop tray and menu bar; [testing](../../specs/testing.md) §Layers, §Rules; [i18n](../../specs/i18n.md) §Terminology. Read only the sections a task names.

## Global constraints

- **Direction** (maintainer, 2026-11-01): 90s console hardware. Lemur palette (charcoal mask and tail stripes, warm stone-grey fur = console plastic, bone-white rings, amber eyes); the four face-button colors (green, blue, amber, red) as status colors; a 90s-console lavender as the brand accent (amber is reserved for attention); plastic-panel surfaces (flat tone + 1 px two-tone bevel, no shadows); cartridge-shaped game cards. Calm, playful, never childish ([design-system §Principles](../../specs/ui/design-system.md#principles)). Pixel art is deferred (mascot and empty states only, later); 3a uses the vector mark there.
- **Modularity is the point.** No color, duration, radius, size, spacing, opacity or font-family literal in `app/lib/` outside `app/lib/design/tokens/` (generated). `cargo xtask brand --check` enforces it (Task 2, `literals.rs`). Never hand-edit a generated file. Generated Dart files start with `// GENERATED by cargo xtask brand from brand/. Do not edit.` then `// dart format off`; generated SVGs carry the same text as an XML comment; binary outputs are listed in `brand/README.md`.
- **Determinism:** same sources + same `Cargo.lock` → byte-identical outputs on Linux x86_64 (the CI runner). On other hosts `--check` compares the text outputs and the binaries' existence only, and prints a warning.
- F1/F2/F3 and the [lemusync-ui recipe](../../../.claude/skills/lemusync-ui/SKILL.md) hold for every widget: tokens only, no `Platform.isX` visuals, `LsSize.target` (48) touch targets, semantics labels, reduce-motion, 200 % text scale, `const`, `RepaintBoundary` around animated status. Color is never the only signal (also icon or text or shape).
- **Contrast:** text pairs ≥ 4.5:1, non-text UI pairs ≥ 3:1 (WCAG 2.2 AA); in the high-contrast themes text ≥ 7:1 and non-text ≥ 4.5:1. The generator enforces every pair listed in `tokens.toml`.
- **P6:** every new user-facing string goes into `app/lib/l10n/app_en.arb` (with `@description`) and `app_es.arb`; `cargo xtask i18n-check` and `flutter gen-l10n` pass. The exact keys and texts are given in the tasks.
- **Flutter tests:** every widget test calls `await loadBrandFonts()` in `setUpAll` (real fonts, so 200 % overflow checks measure the real metrics). Golden tests carry `@Tags(['golden'])` (declared in `app/dart_test.yaml`) and `skip: !Platform.isLinux`; they use `pump()`, never `pumpAndSettle()` (indeterminate animations never settle). Every new or changed golden PNG is opened and reviewed ([testing §Rules](../../specs/testing.md#rules)).
- **Licenses:** fonts SIL OFL 1.1, Lucide ISC, the Lucide Flutter package MIT; each license text ships as an app asset and is registered with `LicenseRegistry`. Rust deps pass `cargo deny check`. Record source URL, version/commit and SHA-256 of every vendored binary (W3).
- No new dependency in any shipped Rust crate (tray pixmaps are raw bytes, no decoder).
- One responsibility per file (B1). xtask brand code lives in `xtask/src/brand/`. Clippy pedantic with `-D warnings`: no bare `as` casts between numeric types (use `try_from`/`from`, or a per-function `#[allow]` with a reason comment).
- Paths from data (part names, Contents.json file names) must match `^[A-Za-z0-9@._-]+$`, contain no `..`, and are joined only under their fixed directory ([security skill](../../../.claude/skills/lemusync-security/SKILL.md)).
- W5: Conventional Commits; the maintainer is the author; the only trailer is `Co-Authored-By: Claude <noreply@anthropic.com>`. No session links.
- Each task ends with `just check` green, then its commit. Tick the task's boxes and update this plan's board row in `docs/progress/README.md` in that commit.
- Toolchain PATH on the maintainer's PC: `export PATH="$HOME/.local/bin:$HOME/development/flutter/bin:$HOME/.cargo/bin:$PATH"`.
